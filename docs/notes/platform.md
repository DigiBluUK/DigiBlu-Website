## Production hardening (9 Sep 2026)

Done on `dev` ahead of go-live, from the outstanding-items review:

- **Security headers on every route** (`next.config.ts` `headers()`, which the Worker honours; `public/_headers` reaches static assets only): a Content Security Policy allowing the site itself plus the two Google hosts the consent-gated analytics uses (`googletagmanager.com` for the script, `google-analytics.com` / `analytics.google.com` for collection) and, since 11 Sep 2026, `challenges.cloudflare.com` for the contact form's Turnstile script and iframe, and nothing else - `frame-src` that host only (it was none), `object-src` none, `frame-ancestors` none, `base-uri`/`form-action` self, `upgrade-insecure-requests`; HSTS for a year with subdomains (no `preload` yet - it is hard to undo, add it once every subdomain is known to serve HTTPS); `nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`, a Permissions-Policy denying camera/microphone/geolocation/payment/USB/FLoC, COOP same-origin. **`'unsafe-inline'` is allowed for scripts and styles on purpose**: Next.js hydrates through inline scripts and the site has three of its own (consent defaults, theme init, JSON-LD); a per-request nonce needs middleware and would make every page dynamic. `'unsafe-eval'` is granted to the dev server only (React's development build wants it for its debugging tools and says so in the console; production never uses it). Verified through the Worker with `curl -I`.
- **Previews are not indexable**: `NEXT_PUBLIC_ROBOTS=noindex` on any non-production environment makes `robots.txt` disallow all and adds `X-Robots-Tag: noindex, nofollow` to every response. Production leaves it unset. CI builds with it set (there has been no CI since 14 Sep 2026; Workers Builds sets it on every non-production branch).
- **A branded 404** (`app/not-found.tsx`): the standalone pages' chrome, "That page is not here", noindex, prerendered.
- **Team photos as WebP**: `assets/team/*.webp` (quality 88, alpha kept) beside the PNGs, 2.4MB to 232KB across the eight; the `.tp-*` rules use `image-set()` with the WebP first and the PNG as fallback. Made with the `sharp` that wrangler happens to install; there is no image pipeline of our own.
- **Node pinned** to 24 (`.node-version`, `engines`) so Cloudflare's build image and CI use what the site was built with.
- ~~**CI** (`.github/workflows/ci.yml`): tests, Next build and Worker build on every push and pull request to `dev` and `main`.~~ **Gone since 14 Sep 2026**: there is no CI and no test gate, and Workers Builds deploys every push, so run `pnpm test` (and `pnpm build`, then `pnpm test:pages`) before a release.
- **Housekeeping**: `.env`, `.env.local` and `.env.*.local` are ignored (`.env.example` is committed); `Nick-original-with-background.png`, a raw original moved into the team folder in error and mirrored into `public/`, is deleted from both.
- **Dependency advisories**: production dependencies have none. Four highs sit in build tooling only, one chain through `sharp` inside wrangler/miniflare, never shipped to a browser or the Worker; npm's suggested fix downgrades wrangler, which is not sensible - update wrangler when a clean release lands.

## Cut-over runbook

**Current as of 21 Sep 2026.** What is left is the release and the DNS switch, both coordinated with Radu (DigiBlu's developer), who owns the Cloudflare account and set up Workers Builds on 14 Sep 2026. The original runbook is kept below as history.

Workers Builds deploys `main` to `https://digiblu-website.radu-ghitescu.workers.dev/`. Both addresses are behind Cloudflare Access, so the user checks them in a browser; they cannot be fetched from this machine.
2. **Confirm the production Worker's configuration with Radu** (the `digiblu-website` Worker in the Cloudflare dashboard, production branch `main`):
   - **Build variables**, inlined at build time, so a change needs a new build: `NEXT_PUBLIC_GA_MEASUREMENT_ID=G-RVNLDVSLJ8`; `NEXT_PUBLIC_TURNSTILE_SITE_KEY` set to the production widget's site key, not Cloudflare's test key from `.env.example`; `NEXT_PUBLIC_ROBOTS` **unset** on production (every preview keeps `noindex`); `SITE_ORIGIN` unset (it defaults to `https://www.digiblu.com`, the canonical host since 24 Sep 2026).

Without them `/api/contact` answers 500.
   - The Turnstile widget's allowed hostnames include `www.digiblu.com` (and `digiblu.com`).
